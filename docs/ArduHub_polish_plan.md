# ArduHub: доработка кабинета (шрифты, меню, значки, ИИ-ассистент, компилятор)

Продолжение `ArduHub_dashboard_auth_spec.md`. Задачи с префиксом `F-`. Если этот файл расходится с прежними, главнее этот. Цвета ArduHub не меняются.

## Что видно в последнем видео (сайт на Vercel)

1. **Шрифт слишком крупный.** В уроке конспект, задание, «Ожидаемое поведение» и ответы теста набраны примерно 20 px. Пункты меню и заголовки тоже крупные. Размеры из прошлого плана (20 px для чтения, 32 px для заголовка) оказались великоваты.
2. **Слишком много пунктов меню.** В меню 13 пунктов: Главная, Карта, Уроки, Практика, Словарь, Домашка, Наставник, Мои проекты, Идеи, Миссии, Лидеры, Магазин, плюс «Поиск» и «Профиль».
3. **Компилятор не работает.** При запуске кода красная плашка: «Сервис компиляции сейчас недоступен или занят». Урок дальше «Проверить схему» не проходит.
4. **Счётчики без значков.** «1 Серия», «55 Искры», «48 Токены» выглядят как обычный текст с крошечными иконками.
5. **ИИ-ассистента не найти.** Это жёлтый круг с молнией в углу, он не похож на помощника. Молния ещё и дублируется в левой полосе урока.
6. **Чат не по-человечески.** Наставник открывается как узкая панель сбоку, а не как привычный чат по центру.
7. **Видео-шаг:** на шаге «Видео» урока 2 большой чёрный прямоугольник без заголовка и состояния загрузки.

## ИИ-ассистент

- **Кнопка:** фигурка выбранного наставника (круглое изображение 64 px с рамкой янтарного цвета и мягкой пульсацией), внизу справа. При первом визите над ней подсказка «Спроси наставника». В кнопке нет значка молнии. Молния в левой полосе урока удаляется, вместо неё миниатюра наставника с подписью «Наставник».
- **Чат по центру:** при нажатии открывается окно по центру экрана с затемнением фона, ширина до 760 px, высота до 80% экрана (на телефоне во весь экран). Сверху: аватар наставника, имя, пометка «Учебный наставник», переключатель наставника, кнопки «Свернуть» и ✕. Посередине лента сообщений: сообщения ученика справа, ответы наставника слева с аватаром, блоки кода с кнопкой «Копировать». Над полем ввода быстрые кнопки («Объясни ошибку», «Дай подсказку», «Проверь мою схему», «Что дальше?») и серая строка «Наставник видит: урок 2, шаг «Код»». Внизу поле ввода (растёт до 5 строк), `Enter` отправляет, `Shift+Enter` новая строка, кнопка отправки, во время ответа кнопка «Остановить». Рядом маленький счётчик токенов.
- **Состояния:** пустой чат с приветствием, индикатор набора, потоковый вывод текста, ошибка (мягкое сообщение и «Повторить»), нет токенов.
- **Управление:** `Esc` закрывает, фокус в поле ввода при открытии и возвращается на кнопку при закрытии, окно ловит фокус, лента прокручивается вниз при новых сообщениях, кнопка «Вниз» если пользователь прокрутил вверх.
- **История:** хранится по каждому наставнику.
- **Из урока:** кнопки «Спросить ИИ» и «Объяснить задание» открывают то же окно с подготовленным контекстом.
- **Размеры текста в чате:** 15 px (`body`), сообщения читаются без напряжения.

## Компилятор (что должно работать)

1. Кнопка «Запустить» компилирует код и запускает схему.
2. Если сервис недоступен, ученик видит точную причину: «Компилятор не настроен» (для администратора), «Сервис просыпается, подожди до 30 секунд», «Сервис занят, повторим автоматически», «Ошибка в твоём коде» (с подсветкой строки).
3. Для правильных эталонных решений уроков и готовых идей запуск работает мгновенно из заранее собранного кэша, даже если сервис выключен.
4. На странице `/dev/status` видно, достижим ли компилятор.

**Вероятные причины, почему не работает (проверять по порядку):**
1. Переменные `COMPILER_URL` и `COMPILER_SECRET` не добавлены в Vercel (файл `.env.local` на Vercel не попадает).
2. Контейнер с Arduino CLI не развёрнут на хостинге (код есть, сервера нет).
3. Бесплатный хостинг «засыпает» при простое, первый запрос долгий.
4. Лимит времени серверной функции Vercel на вашем тарифе короче, чем время компиляции.
5. Несовпадение секрета или адреса.
6. В образе нет установленного ядра `arduino:avr` и библиотек (скачиваются при первом запросе и не успевают).

Какая из причин ваша, определит задача F-5.

# SECTION 2: PLAN (кратко)

- Стек и структура остаются прежними (Next.js, Tailwind, `motion`, Supabase).
- Иконки: собственные SVG-компоненты в `src/components/icons/`, цвет через `currentColor` и токены.
- ИИ-ассистент: компоненты `MentorFab` и `MentorChatDialog` в `src/components/mentor/`, один общий источник состояния чата (`useMentorChat`), вызов из любой страницы функцией `openMentor({ context, prompt })`.
- Фигурки наставников берутся из `public/cabinet/mentors/*.png` (персонажи Вольтик, Ома, Резик, Шина уже есть на странице «Наставники»). Если файла нет, показывается SVG-заглушка.
- Компилятор: сервис в `compiler-service/` (Docker, Arduino CLI), маршрут `/api/compile` проксирует запрос, коды ошибок различаются:

```
POST /api/compile → 200 { hex }  |  400 compile_error { diagnostics }
  503 compiler_unconfigured | 503 compiler_unreachable | 504 compiler_timeout | 429 compiler_busy | 413 code_too_large
```

- Кэш прекомпилированных решений: `public/hex/index.json` (хеш нормализованного кода → путь к `.hex`), нормализация убирает комментарии и лишние пробелы, чтобы правки комментариев не ломали попадание в кэш.

[ASSUMPTION: на хостинге компилятора возможны «засыпание» и холодный старт, поэтому нужен регулярный пинг `/health` внешним сервисом (на бесплатном тарифе Vercel крон-задачи выполняются редко). Условия тарифов хостингов проверьте при выборе]
[ASSUMPTION: время выполнения серверной функции `/api/compile` ограничено тарифом Vercel, поэтому F-5 должна проверить лимит и при необходимости вызывать компилятор через короткие запросы с повтором]
