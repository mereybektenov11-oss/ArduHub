## Проверки в ходе реализации

- L2-1–L2-3: типы, каталог и эталонные схемы проверены; получены настоящие
  HEX для шести доверенных программ официальным Arduino CLI 1.5.1 / AVR 1.8.8.
  Unit-интеграция подтвердила GPIO, INPUT_PULLUP, ADC, PWM и Serial.
- L2-4–L2-6: build и lint пройдены. Первый урок прошёл весь цикл в браузере;
  подтверждены сохранение, переименование, импорт, экспорт и удаление проекта.
- Всего 105 unit/API/интеграционных тестов прошли. Пять критических модулей
  v2 имеют 100% покрытия веток, строк, функций и выражений: преобразование
  графа, миграция, проверка схемы, поведение и объяснение ошибок.
- Покрытие чистой логики измеряется отдельно от исполнения AVR: трассировка
  покрытия значительно замедляет инструкции процессора. Шесть симуляторных
  сценариев выполняются без покрытия при обычном `pnpm test`.
- Поиск 21st не выполнился без входа. Запуск 21st Review отклонён автоматической
  проверкой разрешений из-за возможной передачи исходников внешнему сервису.
  Используются проектные примитивы; качество проверяется локально.
