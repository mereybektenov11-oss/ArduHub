## Что требует внешнего подключения

- В окружении отсутствуют `YOUTUBE_API_KEY`, `GROQ_API_KEY` и `COMPILER_API_URL`. Проверено только наличие переменных, без вывода секретов.
- **Реальные видео не подобраны:** `content/lesson-videos.json` пуст. Resolver, сохранение, кэш, ограничения и интерфейс реализованы; без ключа доступен конспект. Педагогическое качество будущего автоматического подбора ещё нужно просмотреть.
- **Реальный Groq не подключён.** Его время первого токена и фактический ответ не проверены. Ошибки 401/429/5xx проверены тестами; без ключа работают обозначенные бесплатные шаблоны.
- **Docker отсутствует.** Образ и отдельная задача CI подготовлены; контейнерный запуск и удалённый CI не выполнялись. Для произвольного кода нужен изолированный сервис. Без него запускаются только точные доверенные примеры, другой код не подменяется чужой прошивкой.
- Supabase и Vercel не созданы: регистрации, подключённой базы и публикации нет.
- Необязательный этап L2-11 пропущен. Сложные модули, NeoPixel и дополнительные платы остаются визуальными; их симуляция не заявлена.

Инструкции подключения находятся в README и `compiler-service/README.md`. Ключи сохраняются локально на сервере, в чат их передавать не нужно.
