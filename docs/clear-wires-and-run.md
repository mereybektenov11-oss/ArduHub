# Очистка проводов и локальная компиляция — 17.10.2026

- Возле масштаба появилась кнопка «Убрать все провода». Она удаляет только соединения, сохраняет компоненты и их позиции, отменяет начатое соединение и записывает одно действие в историю. Доступны отмена/повтор, изменения сохраняются в черновике. Во время симуляции редактирование закрыто; рядом доступна кнопка остановки.
- «Запустить» теперь всегда находится в верхней панели Workspace: в схеме, коде, тестах и мониторе порта. Дублирующая кнопка внизу урока удалена.
- Подключён установленный Arduino CLI через локальный gateway на 127.0.0.1:8081. Изменённый код компилируется в настоящий HEX и выполняется AVR Worker в браузере. Точные учебные примеры используют существующий кэш до обращения к сервису, в том числе при его недоступности.
- Ошибки компиляции возвращаются в редактор с номером строки. Сообщение о недоступном сервисе больше не утверждает, что он вообще не подключён.

Native-режим включён явной локальной настройкой `LOCAL_COMPILER=true`, URL и случайный ключ находятся в игнорируемом `.env.local`. Это режим разработки собственного кода, без контейнерной изоляции: не публиковать его в интернете. Gateway требует ключ и слушает loopback. Next API дополнительно проверяет Host и Origin. Заголовки ограничены allow-list, разрешены числовые макросы; другие директивы, token-pasting, ассемблер и альтернативные записи препроцессора отклоняются. Компилятор не получает ключей платформы. Таймаут, один параллельный запрос, ограничение размера и проверка временной папки сохранены; в Windows при таймауте завершается дерево процессов.

Docker-режим остаётся настройкой gateway по умолчанию для недоверенного кода. Его запуск на этом компьютере не проверен. Инструкции находятся в `compiler-service/README.md`.

Проверено: production build, линтер, TypeScript, lint:type, форматирование и отсутствие серверных секретов в клиенте. 12 целевых модульных проверок прошли; среди них ограничения native-режима и запрет cross-origin/non-loopback запросов. Пройдены 9 разных браузерных сценариев: полный урок, проекты, монитор порта, доступность мобильного экрана, запуск из «Тестов», работа с проводами, очистка всех проводов с отменой/повтором и исполнение изменённого скетча. Последний сценарий проверен отдельно после уточнения селектора диагностического сообщения в тесте.

Проверенный изменённый скетч печатает `Edited 137` и использует паузы 137/251 мс. API ответил `source: service`, текст появился в мониторе порта; намеренно пропущенная точка с запятой вернула ошибку редактора. Это реальная компиляция и выполнение, без подмены ответа тестовыми данными.
