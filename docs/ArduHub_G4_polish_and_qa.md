# ArduHub: исправления, файл 4 из 4. Достижения, лендинг и итоговая проверка

**Что в этом файле:** задачи G-15 (по желанию), G-16 (по желанию) и G-17 (итоговая проверка качества). **Перед началом должны быть выполнены файлы 1, 2 и 3.**

Это часть большого плана исправлений кабинета ArduHub (задачи G-1 … G-17). Полный план в одном файле: `ArduHub_big_fix_plan.md`. Файлы выполняются по порядку: 1, 2, 3, 4. Палитра интерфейса прежняя (зелёно-чёрный, кремовый, янтарный), для значков разрешены тематические цвета. Каждая задача выполняется в отдельной сессии, а после каждой задачи тесты, `pnpm lint`, `pnpm build` должны быть зелёными.

---

## Общие правила для всех задач

1. Тексты только из `content/*.ts`, проверяются `pnpm lint:copy` (см. G-2).
2. Размеры шрифтов только по токенам «Типографика v2» (`F-1`), цели нажатия не меньше 44 px.
3. Анимации через `motion.ts` (`transform` и `opacity`), при «уменьшить анимацию» движение заменяется мгновенной сменой состояния.
4. Звуки только через `playSfx(id)` из `sfx.ts`, никаких `new Audio()` в компонентах.
5. Каждая задача заканчивается тестами из её критериев. Задача не считается готовой, пока тесты зелёные.
6. Служебные страницы (`/dev/*`) не попадают в меню и `sitemap.xml`.

# ЗАДАЧИ

## Task G-15 (по желанию): Стикеры-достижения

**What to build:** Набор из 12 тематических стикеров: «Первый огонёк» (урок 1), «Светоносец» (все уроки про светодиоды), «7 дней подряд», «Без ошибок» (урок с первой попытки), «Мастер проверки» (5 безошибочных), «Изобретатель» (первый проект), «Покупатель» (первая покупка), «Друг наставника» (10 вопросов наставнику), «Скорость» (10 верных подряд в блице), «Исследователь» (попробовал все темы), «Электрик» (10 уроков), «Лучший в неделе» (в топ-3 лидеров). Раздел «Мои стикеры» в профиле: полученные цветные, остальные тёмные силуэты с подсказкой условия. Получение: окно со стикером, вспышка, звук `level_up`, небольшая награда искрами.
**Files likely affected:** `src/domain/achievements.ts`, `src/components/profile/Stickers.tsx`
**Acceptance criteria:**
1. Unit-тесты условий всех 12 стикеров (выполнено и не выполнено).
2. Раздел показывает 12 ячеек, полученные цветные, остальные силуэты.
3. Получение стикера показывает окно один раз и начисляет награду один раз.
**Dependencies:** G-8, G-9, G-10

## Task G-16 (по желанию): Лендинг под настоящий продукт

**What to build:** Привести тексты лендинга в соответствие с работающим кабинетом: кнопки «Начать» ведут в `/app` (или в окно знакомства), строки «Платформа в разработке», «Записаться на ранний доступ» и «Скоро» убрать, тарифный блок показывает только то, что работает (Pro скрыть до появления), форма почты остаётся как «Узнавать о новых уроках». Добавить в `pnpm lint:copy` проверку лендинга.
**Files likely affected:** `src/content/ru.ts`, `src/components/sections/*`
**Acceptance criteria:**
1. Основная кнопка hero открывает кабинет, на лендинге нет фраз «в разработке», «Скоро», «ранний доступ».
2. Блок тарифов не содержит неработающих планов.
3. `pnpm lint:copy` проходит и на лендинге.
**Dependencies:** G-2

## Task G-17: Проверка качества

**What to build:** E2E-сценарий «новый ученик»: окно «Как тебя зовут?» → главная без баннеров, ровно один «Продолжить» → урок 1: видео → тест (неверный ответ: тряска и `wrong`, верный: `correct`) → практика (подзадачи отмечаются со звуком и анимацией) → запуск (на подменённом компиляторе и без него) → окно «Урок пройден!» → главная: узел 1 горит, урок 2 текущий, остальные закрыты, карта показывает то же → магазин: покупка с анимацией, отказ при нехватке искр → проверка отсутствия кнопки наставника на страницах вне обучения. Тест обхода страниц на запрещённые слова. Проверка звука (выключатель сохраняется). Мобильный 360 px, режим «уменьшить анимацию». Скриншоты `/dev/icons` и карты на 360, 768, 1440. Axe, Lighthouse на `/app`, замеры производительности анимаций (частицы убираются, нет утечек).
**Files likely affected:** `tests/e2e/*.spec.ts`, `lighthouserc.json`
**Acceptance criteria:**
1. Весь сценарий «новый ученик» проходит автоматически.
2. Тест обхода страниц не находит запрещённых слов, на страницах вне обучения нет кнопки наставника.
3. Axe не находит нарушений serious и critical, Lighthouse Accessibility на `/app` не ниже 95.
**Dependencies:** G-1 … G-14

# Итоговая приёмка всего плана

```
Given новый ученик открывает кабинет впервые
When окно «Как тебя зовут?» закрыто вводом ника
Then он видит главную с приветствием, одной большой кнопкой «Продолжить», одним текущим узлом на пути, и нигде нет слов «гость», «демо», «скоро», «в разработке»

Given у ученика пройден только урок 1
When он открывает путь, карту и список уроков
Then во всех трёх местах открыт только урок 2 и больше никакие уроки не открыты

Given ученик отвечает на вопрос теста неверно
When ответ выбран
Then карточка трясётся, играет мягкий низкий звук, а пояснение выезжает снизу, при верном ответе галочка рисуется и играет звук «верно»

Given ученик проходит урок до конца
When проверка практики пройдена
Then появляется окно с конфетти и звёздами, играет фанфара, числа награды считаются, а после возврата на путь узел урока горит и следующий открывается со щелчком замка

Given ученик занимался сегодня
When он смотрит на значок серии
Then это красно-оранжевое мерцающее пламя, а при серии ноль дней это погасший серый огонёк

Given ученик находится на главной, карте, в магазине или лидерах
When он смотрит на экран
Then плавающей кнопки наставника нет

Given ученик находится на этапе «Практика» и дважды подряд неудачно проверил схему
When проходит пауза в секунду
Then рядом с портретом наставника появляется мягкая подсказка, которую можно закрыть

Given компилятор развёрнут и подключён
When ученик меняет задержку в коде урока и нажимает «Запустить»
Then светодиод мигает с новым периодом

Given компилятор выключен, а код ученика простой
When ученик нажимает «Запустить»
Then код запускается без сервера, а при трёх сбоях сервера появляется «Проверить по образцу»

Given ученик покупает предмет в магазине
When подтверждение получено
Then играет звук покупки, на карточке появляется штамп «Куплено», баланс уменьшается плавно и предмет летит во вкладку «Мои предметы»

Given открыта карта на экранах 360, 768 и 1440 px
When карта загрузилась
Then метки стоят на нарисованных объектах, на метках нет портрета наставника, картинка не обрезана
```
