## Подтверждённые ограничения

- Supabase/Vercel не созданы, регистрации и публикации нет.
- Ключи YouTube/Groq не заданы. Это подготовленные интеграции с проверенными контрактами, не доказательство реального провайдерного ответа или выбранного видео.
- Без изолированного сервиса можно запускать только точные доверенные исходники из fixtures. Произвольный код на хосте не компилируется.
- Указанные в исходном плане Llama сняты с обычного Groq-доступа. На17.10.2026 сверены официальные docs: defaults openai/gpt-oss-120b и openai/gpt-oss-20b, с возможностью переопределения окружением.
- Не моделируются реальные токи, напряжения, повреждения компонентов. Пины I2C имеют фиксированные адреса учебных устройств.
