# ArduHub: исправления, файл 2 из 4. Удобство для школьника и наставник

**Что в этом файле:** задачи G-5, G-6, G-7, G-13. Упрощают интерфейс (главная, практика, проекты, магазин по структуре, урок) и оставляют ИИ-наставника только там, где идёт обучение. **Перед началом должен быть выполнен файл 1** (задачи G-1 и G-2: единый прогресс и чистка текстов).

Это часть большого плана исправлений кабинета ArduHub (задачи G-1 … G-17). Полный план в одном файле: `ArduHub_big_fix_plan.md`. Файлы выполняются по порядку: 1, 2, 3, 4. Палитра интерфейса прежняя (зелёно-чёрный, кремовый, янтарный), для значков разрешены тематические цвета. Каждая задача выполняется в отдельной сессии, а после каждой задачи тесты, `pnpm lint`, `pnpm build` должны быть зелёными.

# ЧАСТЬ B. Решения для этого файла

## B1. Принципы интерфейса для школьника

1. **Одно главное действие на экран.** На главной это «Продолжить урок», в уроке «Запустить» или «Дальше».
2. **Не больше трёх блоков в первом экране.** Всё остальное ниже или за кнопкой.
3. **Короткие тексты.** Подсказка до 12 слов, карточка до двух строк, обращение на «ты», без терминов без пояснения.
4. **Крупные цели нажатия.** Не меньше 44 px по высоте и ширине, скругление 16-24 px.
5. **Отклик на каждое действие** в течение 100 мс: анимация и звук (если звук включён).
6. **Ошибки дружелюбные.** Не «Ошибка», а «Почти получилось! Проверь резистор». У каждой ошибки следующий шаг.
7. **Не показываем того, чего нет.** Нет Pro-тарифа, расписания, домашки от учителя: нет и карточек про них.
8. **Не говорим «демо», «гость», «скоро», «в разработке», «заглушка», «учебная модель».**

## B2. Список запрещённых слов и замен

| Было | Стало |
|---|---|
| «гость», «гостевой» | убрать, сохранение показывается как действие «Сохранить прогресс» (см. B3) |
| «демо», «демонстрация», «демо-кабинет» | убрать |
| «Скоро», «в разработке», «Подписки пока недоступны» | убрать элемент целиком |
| «Учебная модель: соединения и цифровые сигналы…» | убрать, при необходимости «Светодиод загорится, когда всё собрано верно» |
| «Готово к запуску» | «Нажми ▶, чтобы запустить» |
| «Работает в симуляции» | «Можно запустить» |
| «Только внешний вид» | «Пока без запуска» |
| «Импорт JSON», «Экспорт JSON» | «Загрузить проект», «Скачать проект» в меню «⋯» |
| «Юный изобретатель» | ник ученика |
| «ARDUHUB LAB», «Понимать — значит пробовать» | убрать |
| «Схема и код сохраняются на этом устройстве» | убрать (сохранение автоматическое, показывается значок «Сохранено» на секунду) |
| «Проверенные примеры из «Идей» можно запускать из кэша» | убрать |
| «Пример расписания», «Заработай XP, чтобы попасть в таблицу» | «Стань первым!» с картинкой подиума |

Правило проверяется автоматически (задача G-2): тест просматривает все тексты интерфейса и падает, если встречает слова из списка.

## B8. Наставник только в обучении

| Где | Показывать наставника? | Как |
|---|---|---|
| Главная, Карта, Практика (игры), Лидеры, Магазин, Профиль, Идеи, список проектов | Нет | никакой плавающей кнопки |
| Урок, этап «Видео» | Да, тихо | значок в левой полосе, без плавающей кнопки |
| Урок, этап «Тест» | Да | после неверного ответа кнопка «Объясни» рядом с пояснением открывает чат с вопросом |
| Урок, этап «Практика» | Да | кнопка «Спросить наставника» в панели действий, значок в левой полосе, мягкая подсказка от наставника (маленький пузырь рядом с портретом) после двух неудачных проверок подряд или 3 минут без действий, не чаще раза за этап, закрывается крестиком |
| Редактор проекта | Да | кнопки «Спросить наставника» и «Разбор проекта» в панели |
| Мини-игры | Только после проигрыша | кнопка «Разбор ошибок» на экране результата |

Чат остаётся окном по центру (F-4). Подпись под портретом без переноса слов. «Сменить наставника» переезжает в «Профиль» и внутрь самого чата.

## Общие правила для всех задач

1. Тексты только из `content/*.ts`, проверяются `pnpm lint:copy` (см. G-2).
2. Размеры шрифтов только по токенам «Типографика v2» (`F-1`), цели нажатия не меньше 44 px.
3. Анимации через `motion.ts` (`transform` и `opacity`), при «уменьшить анимацию» движение заменяется мгновенной сменой состояния.
4. Звуки только через `playSfx(id)` из `sfx.ts`, никаких `new Audio()` в компонентах.
5. Каждая задача заканчивается тестами из её критериев. Задача не считается готовой, пока тесты зелёные.
6. Служебные страницы (`/dev/*`) не попадают в меню и `sitemap.xml`.

**What to build:** Новая главная по принципам раздела B1. Справа (от 1200 px): «Миссии на сегодня» (3 компактные строки с иконками) и «Серия» (календарь на 7 дней), больше ничего. Единовременная карточка «Не знаешь, с чего начать? Пройди короткий тест» (закрывается). В меню убрать «–» сворачивания групп (группы всегда раскрыты), «Поиск» на планшете и телефоне становится иконкой. Убрать кнопки «Пройти тест» и «Все уроки» рядом с заголовком.
**Files likely affected:** `src/app/app/page.tsx`, `src/components/home/*`, `src/components/shell/*`
**Acceptance criteria:**
1. На 1440×900 в первом экране центра ровно три блока: приветствие с значками, карточка «Продолжи…», начало пути. В правой колонке только «Миссии на сегодня» и «Серия».
2. На странице ровно одна метка «Продолжить» на узле и одна главная кнопка «Продолжить» в карточке, у остальных узлов кнопок нет.
3. Нет хлебных крошек, кнопок «Пройти тест» и «Все уроки», баннера сверху, карточек «Факт дня», «ArduHub Pro» и превью лидеров.

## Task G-6: Остальные экраны: Практика, Проекты, Идеи, Лидеры, Профиль, Магазин (структура)

**What to build:**
- **Практика:** вкладки «Тренировки» и «Словарь» (вкладка «Домашка» скрыта, пока в продукте нет выдачи заданий). Убрать плитки тем, фильтр уровней, лозунг и «0 ошибок для повторения».

**Files likely affected:** `src/app/app/practice/*`, `src/app/app/projects/*`, `src/app/app/ideas/*`, `src/app/app/leaderboard/*`, `src/app/app/profile/*`, `src/app/app/shop/*`

**What to build:** Правила показа по таблице B8. Убрать глобальную плавающую кнопку наставника из общего каркаса.
