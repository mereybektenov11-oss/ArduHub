## Границы

- Supabase и Vercel не созданы. Нет заявлений о реальной облачной авторизации, синхронизации или публикации.
- Гостевая сборка доступна без Supabase. Для строгой проверки обязательной конфигурации установите `AUTH_REQUIRED=true`.
- SQL проверяется в настоящем PostgreSQL-движке PGlite с локальным auth.uid и ролями. Это не проверка облачного PostgREST/Auth или нагрузки нескольких независимых соединений.
- Внешний поиск 21st с контекстом исходников отклонён автоматической проверкой. Работа продолжена по локальным референсам, исходники не отправлялись.
- Полноценная сборка произвольного Arduino-кода по-прежнему требует отдельного изолированного сервиса.

Итог и точные ограничения: [dashboard-verification.md](dashboard-verification.md). Реализация проверена локально; облачная авторизация и JS-бюджет не объявляются завершёнными.
