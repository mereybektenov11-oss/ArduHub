# Проверка обучения ArduHub v2

Дата: 16 октября 2026 года. Источник требований:
`docs/ArduHub_learning_v2_spec.md`. Оригинал пользователя сохранён без изменений.

## Что готово

- Три практических урока: «Первый огонёк», «Свет по кнопке», «Яркость и сигнал».
  Пять шагов, последовательный доступ, конспект, проверка схемы, режимы fill/fixbug/write,
  трёхступенчатые подсказки и восстановление черновика. Награда только после
  проверки поведения, повторно XP не начисляются.
- Wokwi Elements 1.9.2: 14 видов деталей в проектах. Координаты и имена пинов
  извлечены из настоящего `pinInfo`, генератор воспроизводим. Старый редактор
  прямоугольников удалён. Есть перетаскивание, клавиатура, провода, цвета,
  изгибы, поворот, номинал резистора, удаление, undo/redo и сенсорные соединения.
- Код C++ в CodeMirror с подсветкой синтаксиса и диагностикой строк. Лимит 16 КБ,
  словарь русских объяснений, запрос наставнику, повтор при недоступном сервисе.
- AVR8js 0.21.1 исполняет настоящие HEX в Worker: GPIO, таймеры, INPUT_PULLUP,
  ADC, PWM, Serial. LED/RGB, кнопка, переключатель, потенциометр, AO фоторезистора
  и зуммер с измерением частоты связаны с графом. Стоп завершает Worker и гасит выходы;
  скрытие вкладки приостанавливает симуляцию и звук. Проект работает до остановки.
- «Мои проекты» и шесть идей: создание, редактирование, локальное сохранение,
  переименование, подтверждаемое удаление, JSON-экспорт/импорт с валидацией.
  До 20 проектов, 200 КБ на проект; повреждённый импорт не заменяет существующие данные.
- Разбор проекта содержит три раздела; без провайдера явно используется
  учебный шаблон. Новые режимы API наставника: compile_error и project_review.
- Dockerfile, изолированный compiler gateway, серверный `/api/compile`,
  лимиты и SHA-256-кэш подготовлены. MIT-лицензии сохранены и показаны на `/app/about`.

## Подтверждённые проверки

- Build, TypeScript, lint и форматирование пройдены.
- 105 unit/API/интеграционных тестов пройдены. Реальные прошивки проверили
  мигание за 3,2 с виртуального времени, нажатую/отпущенную кнопку, analogRead,
  среднюю PWM-яркость и Serial. Постоянный HIGH не проходит как мигание.
- Пять критических модулей v2: 100% строк, веток, функций и выражений
  (145/145 выражений, 136/136 веток, 51/51 функций, 121/121 строк).
  Старые девять критических модулей сохранили 100% покрытия.
- Полный регрессионный прогон: **60 браузерных сценариев прошли за 4 минуты**.
  Включены лендинг, анимации, кабинет, все три урока, чужой ID кнопки,
  реальные Worker/Serial, нулевая награда за один монтаж, восстановление,
  JSON-перенос, удаление, сенсорное управление и axe на 360 px.
  Serious/critical нарушений в проверенных состояниях нет.
- После дополнительного исправления выключения питания при «Стоп» выполнен
  новый прогон 105 unit-тестов; после оптимизации загрузки все 16 сценариев
  обучения и кабинета прошли за 1,2 минуты, включая загрузку всех 14 деталей.

Локальные артефакты: `reports/learning-v2/e2e-full-60/index.html`,
reports/learning-v2/e2e-final-16/index.html, скриншоты урока и мобильного проекта, `coverage/learning-v2/index.html`.
Нагрузка на production-сборке, Chrome 1440×1000: 60 деталей, 120 проводов,
работающий Worker, наблюдение 3 с. Средняя частота **56,33 FPS** (порог 55),
P95 кадра 16,9 мс, максимальный кадр 184,29 мс. Средний порог выполнен;
единичная задержка при начале отрисовки видна в максимуме и не скрыта из замера.

JavaScript редактора с основной палитрой и открытой вкладкой кода —
389 433 байта gzip; вместе с загруженным Worker — **403 806 байт / 394,34 КиБ**,
меньше бюджета 400 КиБ. Детали «Только внешний вид» загружаются при раскрытии
группы; превью — при прокрутке. В измерение включены общие React/Next.js-части.
Ранний замер включал лишнюю предзагрузку соседних страниц; она отключена в
меню кабинета. Для C++ использован официальный компактный StreamLanguage
CodeMirror, без тяжёлого синтаксического дерева: синтаксис, номера строк,
редактирование, undo и диагностики компилятора сохранены.

Данные измерения: `reports/learning-v2/performance.json`.

Lighthouse 13.5, мобильный профиль, production `/app/lesson/lesson-1`:
**Performance 89**, **Accessibility 100**; LCP 3,05 с, TBT 243 мс,
CLS 0,0000702. Порог плана — Performance 80 — пройден.

кода и нагрузочным профилем выше. HTML/JSON:

## Оставшиеся внешние условия и границы

- Docker в текущем окружении не установлен. **Произвольная контейнерная
  компиляция не запущена и не проверена end-to-end.** Без конфигурации работают
  ровно шесть точных доверенных исходников, заранее собранных официальным
  Arduino CLI 1.5.1 / AVR 1.8.8. Это явно подписано в интерфейсе и API
  (`source: precompiled`). Неизвестный код получает 503 с сохранением черновика.
  Настоящие диагностики CLI проверены на заранее заданном ошибочном исходнике;
  браузерная подсветка отдельно проверена с подставленным ответом API.
  Запуск Docker описан в `compiler-service/README.md`.
- Видео команда не предоставила: есть переход к конспекту, а не выдуманный
  видеокурс. Для файлов подготовлен учёт фактического времени без перемотки;
  внешние плееры подтверждаются кнопкой. Реальный просмотр видео не проверен.
- Остальные 12 пунктов старого маршрута помечены подготовительными материалами;
  они не выдаются за готовые практические уроки v2.
- Это учебная цифровая модель прямых соединений, без расчёта токов и напряжений,
  нагрева, макетки и электрических характеристик реальных деталей. Сервопривод,
  LCD, 7-сегментный индикатор, HC-SR04 и DHT22 — только внешний вид.
  Частота зуммера измеряется по переключениям GPIO; программа tone(8, 1000)
  проверена на реальной прошивке. Звук зависит от разрешения браузера на воспроизведение.
- AI-провайдер, Supabase, авторизация, синхронизация и публикация не подключены.
  Шаблонный наставник не утверждает, что исполнил код. Серверные лимиты процесса
  потребуют общего хранилища при нескольких экземплярах сервера.
- 21st поиск не выполнился без входа. Автоматическая проверка разрешений отклонила
  21st Review из-за возможной отправки исходников внешнему сервису. Этот вызов
  не обходился; интерфейс проверен локальными тестами, axe и просмотром кадров.
