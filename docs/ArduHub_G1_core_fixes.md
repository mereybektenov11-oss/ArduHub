## B3. Аккаунт без слов «гость» и «демо»

- Первый вход: окно «Как тебя зовут?» (ник до 20 символов и выбор аватара из 6 вариантов). Ученик сразу попадает в кабинет, никаких баннеров.
- Прогресс сохраняется на устройстве и (если есть аккаунт) на сервере.
- Предложение «Сохрани прогресс» (создать аккаунт или войти) показывается один раз после первого пройденного урока и ещё раз через 7 дней, закрывается крестиком. Постоянного баннера нет. В «Профиле» всегда есть кнопка «Сохранить прогресс».
- На странице входа ссылка «Продолжить как гость» превращается в «Начать без аккаунта».

[ASSUMPTION: режим «без аккаунта» остаётся, чтобы жюри и новые ученики могли попробовать продукт сразу, но его не видно как «гостевого»]

## B4. Правила открытия уроков (единый источник истины)

Одна чистая функция `computeCourseState(course, progress)` возвращает состояние каждого урока. Все экраны (путь, карта, список, карточка узла, индикатор) используют только её.

- Курс это упорядоченный список уроков по главам.
- Состояния: `done`, `current`, `locked`.
- `current` ровно один: первый непройденный урок. Всё после него `locked`. Всё до него должно быть `done`.
- Урок N+1 открывается только после прохождения урока N, глава открывается после прохождения последнего урока предыдущей.
- Этап урока «Видео» считается пройденным только после просмотра 80% или нажатия «Я посмотрел». «Тест» только после порога 70%. «Практика» только после трёх подзадач. Нет «пройдено по умолчанию».
- Уровень ученика считается по XP: Ур.1 с 0, Ур.2 с 100, Ур.3 с 250, Ур.4 с 450, Ур.5 с 700, Ур.6 с 1000.
- Нового ученика: XP 0, серия 0, искры 0, токены наставника 50.

[ASSUMPTION: пороги уровней подобраны мной, их можно менять в одном файле `levels.ts`]

## B9. Компиляция: что делаем

**Диагноз по видео:** текст «Компилятор пока не подключён» означает, что у сайта на Vercel нет адреса или секрета компилятора. Сервис компиляции нужно развернуть отдельно (на Vercel Arduino CLI с ядрами не запускается) и прописать адрес.

**Что делает Codex (G-3):** проверяет, что в репозитории есть рабочая папка `compiler-service/`, доводит до запуска локально в Docker, пишет подробный `compiler-service/RUNBOOK.md`, добавляет проверку «Скомпилировать Blink» на странице `/dev/status`, пишет скрипт дымового теста `pnpm compile:smoke <URL>`.

**Что делает человек** (шаги в конце файла): выкладывает контейнер на хостинг, добавляет `COMPILER_URL` и `COMPILER_SECRET` в Vercel, делает повторный деплой, запускает проверку на `/dev/status`.

**Варианты хостинга** (условия и цены тарифов сверьте на сайтах):

| Хостинг | Плюсы | Минусы |
|---|---|---|
| Render (веб-сервис из Docker) | просто, деплой из GitHub | бесплатный уровень засыпает при простое, первый запрос долгий |
| Railway | просто, деплой из GitHub | нужен платный баланс после пробного периода |
| Google Cloud Run | сервис «просыпается» по запросу, есть бесплатная квота | сложнее настроить, нужна платёжная карта |
| Fly.io | быстрый запуск контейнера | нужна карта |
| Hugging Face Spaces (Docker) | бесплатно | засыпает, ограничения по ресурсам |

**Чтобы урок не ломался из-за сервера (G-4):**
- Правильные эталонные решения и их типичные варианты запускаются мгновенно из заранее собранного кэша.
- Для простых уроков 1-8 работает быстрый запуск без сервера (браузерный интерпретатор простого Arduino-кода). В интерфейсе без слов «режим» и «упрощённый»: просто работает.
- Если сервер недоступен, а код не подходит под быстрый запуск: сообщение «Не получилось запустить, попробуй ещё раз через минуту». После трёх неудач подряд из-за сервера (не из-за кода) появляется кнопка «Проверить по образцу»: код сравнивается с эталоном, урок засчитывается с половиной награды.

[ASSUMPTION: интерпретатор в G-4 поддерживает только простое подмножество Arduino-кода, достаточное для уроков 1-8, остальное идёт через настоящий компилятор]
[ASSUMPTION: «Проверить по образцу» с половиной награды допустимо как аварийная страховка, чтобы школьник не застрял из-за неисправности сервера]

## Общие правила для всех задач

1. Тексты только из `content/*.ts`, проверяются `pnpm lint:copy` (см. G-2).
2. Размеры шрифтов только по токенам «Типографика v2» (`F-1`), цели нажатия не меньше 44 px.
3. Анимации через `motion.ts` (`transform` и `opacity`), при «уменьшить анимацию» движение заменяется мгновенной сменой состояния.
4. Звуки только через `playSfx(id)` из `sfx.ts`, никаких `new Audio()` в компонентах.
5. Каждая задача заканчивается тестами из её критериев. Задача не считается готовой, пока тесты зелёные.
6. Служебные страницы (`/dev/*`) не попадают в меню и `sitemap.xml`.
