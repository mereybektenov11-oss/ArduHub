# SECTION 1: SPEC

## Требования

### Окна по центру
1. Все всплывающие окна и всплывашки с наградами, покупками и сообщениями показываются по центру экрана по горизонтали и вертикали, независимо от прокрутки страницы и размера экрана (360-1920 px).
2. Перечень окон: «Урок пройден!», новый уровень, подтверждение покупки, «Куплено» (если это окно, а не штамп на карточке), сундук за миссии, стикер-достижение (если есть), «Серия N!» и «Заморозка спасла серию!», предложение «Сохрани прогресс», окно «Как тебя зовут?», окно наставника. Всплывающие числа награды вида «+10 искр» (небольшая всплывашка без кнопок) тоже по центру, без блокировки экрана, исчезают сами.
3. Летящие к счётчикам частицы (анимация наград) и штамп «Куплено» на карточке товара остаются как есть: это не окна.
4. Заголовок и основной текст в окнах наград выровнены по центру, кнопки по центру, на узком экране переносятся в столбик.
5. Окно не выше 90% высоты экрана, при нехватке места прокручивается содержимое окна (одна полоса), подложка не прокручивается.
6. Пока окно открыто, страница за ним не прокручивается.
7. Закрытие по `Esc` и по нажатию на подложку (кроме окон, где нужен явный выбор), фокус возвращается на элемент, открывший окно.

### Окно наставника
8. Содержимое схемы, коды сообщений и любые служебные данные не показываются в чате. В ленте только то, что написал ученик (или название быстрой кнопки), и ответы наставника.
9. Ответы наставника отображаются без сырых знаков Markdown: заголовки `#`, звёздочки `**`, обратные кавычки, таблицы и JSON не видны. Допустимы абзацы, **жирный** текст, короткие списки и блоки кода с кнопкой «Копировать».
10. В окне ровно одна вертикальная полоса прокрутки: у ленты сообщений. Шапка и поле ввода всегда видны.
11. Полоса прокрутки тонкая и без стрелок.
12. Новое сообщение прокручивает ленту вниз, если ученик был внизу. Если он прокрутил вверх, показывается кнопка «Вниз».
13. Быстрые кнопки («Объясни ошибку» и др.) занимают одну строку (при нехватке места горизонтальная прокрутка внутри строки, не перенос на три строки).
14. Старые сохранённые чаты очищаются от служебных данных при загрузке.

### Счётчики на главной
15. Значок, число и подпись выровнены: значок слева, справа блок из двух строк (число сверху, подпись снизу, по левому краю), блок по вертикали по центру значка.
16. Все четыре счётчика (серия, искры, токены, уровень) одной высоты, с одинаковыми промежутками. Кольцо уровня и подпись «Уровень» выровнены по тому же центру.
17. Верхняя панель урока со счётчиками остаётся как есть (правка не должна её ломать).

## Edge cases

- **Окно открылось, когда страница прокручена вниз:** оно всё равно по центру экрана.
- **Окно открылось внутри блока с анимацией или `transform`:** окно всё равно по центру экрана (его выносят в `document.body`).
- **Два окна сразу (например, «Урок пройден!» и «Серия N!»):** показываются по очереди (очередь), второе после закрытия первого, всплывашка «+N» не прерывает окно.
- **Содержимое окна выше экрана (360×640):** окно не выше 90% высоты, внутри одна полоса прокрутки, кнопки видны (закреплены внизу).
- **«Уменьшить анимацию»:** окно появляется без движения, но по центру.
- **Мобильная клавиатура в чате:** поле ввода остаётся над клавиатурой, окно не уезжает.
- **Очень длинный ответ наставника или широкий блок кода:** горизонтальная прокрутка только внутри блока кода, не в окне.
- **Старый чат с JSON в истории:** при первой загрузке служебные части вырезаются, сами вопросы и ответы остаются.
- **Модель всё же вернула Markdown-таблицу или JSON:** показывается как обычный текст без символов разметки или скрывается, окно не ломается.
- **Счётчик с трёхзначным числом (например, 1250 искр):** блок растёт вправо, выравнивание не ломается.
- **Узкий экран (360 px):** счётчики в один ряд с переносом по сетке 2×2, выравнивание внутри каждого сохраняется.

## Task H-1: Общий слой для всплывающих окон по центру экрана

**What to build:** Компонент `Overlay` в `src/components/overlay/`: выносится в `document.body` через портал, `position: fixed; inset: 0; display: grid; place-items: center`, затемнение, отступ от краёв 16 px, панель `max-height: 90dvh` с внутренней прокруткой содержимого (если не помещается; кнопки действий закреплены внизу панели), фокус-ловушка, `Esc` и закрытие по подложке (настраивается), `aria-modal`, блокировка прокрутки страницы (`overflow: hidden` на `body` с `scrollbar-gutter: stable`, чтобы страница не дёргалась), анимация появления по существующим токенам (без новых). Вариант `celebration` (по умолчанию `text-align: center` у заголовка и основного текста, кнопки по центру, на узком экране столбиком). Компонент `RewardPopup` для всплывашек «+N», «Серия N!»: по центру экрана, без блокировки (`pointer-events: none`), исчезает сама. Первой исправить «Урок пройден!»: найти причину смещения (контейнер с `transform`, `filter`, `contain`, отсутствие портала) и записать в `docs/H_NOTES.md`.

## Task H-2: Окно наставника: чистый чат и нормальная прокрутка

**What to build:**
- **Источник мусора.** Найти, где служебный контекст (описание схемы, код, этап урока) попадает в видимое сообщение. Разделить: `message` (то, что пишет ученик или название быстрой кнопки) и `context` (передаётся отдельным полем запроса к `/api/mentor`, в ленте не показывается). Плашка «Наставник видит: урок N, этап…» остаётся как отдельная строка интерфейса над полем ввода, не как сообщение. Сообщения роли `context` в ленте не рендерятся.
- **Очистка ответа.** Безопасный отрисовщик Markdown (без сырого HTML): допустимы абзацы, `**жирный**`, `*курсив*`, маркированные и нумерованные списки до 6 пунктов, строчный код, блоки кода с кнопкой «Копировать». Заголовки `#`, таблицы, горизонтальные линии и JSON приводятся к простому тексту. Системный промпт наставника дополнить: «Пиши простым текстом короткими абзацами, без таблиц, без заголовков, без JSON и служебных данных, без пересказа схемы целиком».
- **Прокрутка.** Подложка и панель окна: `overflow: hidden`, панель `display: flex; flex-direction: column; height: min(720px, 90dvh)`. Шапка и поле ввода закреплены. Лента сообщений: `flex: 1; min-height: 0; overflow-y: auto; overscroll-behavior: contain`, это единственный прокручиваемый элемент. Тонкая полоса прокрутки (`scrollbar-width: thin`, WebKit: узкая полоса со скруглением, без стрелок `::-webkit-scrollbar-button { display: none }`). Автопрокрутка вниз при новом сообщении, если ученик внизу (допуск 80 px), иначе кнопка «Вниз». Быстрые кнопки одной строкой с горизонтальной прокруткой внутри строки. На мобильном окно во весь экран (`100dvh`), поле ввода над клавиатурой (`visualViewport`). Блоки кода прокручиваются по горизонтали внутри себя.
- **Старая история.** Одноразовая миграция сохранённых чатов: из сообщений вырезаются служебные фрагменты («Наставник видит: …» и JSON схемы), версия хранилища повышается.
**Files likely affected:** `src/components/mentor/*`, `src/lib/mentor/*`, `src/services/mentor/prompts.ts`, `src/app/api/mentor/route.ts` (только приём отдельного поля `context`), стили окна
**Acceptance criteria:**
1. При открытом окне и 30 сообщениях вертикальной прокруткой обладает ровно один элемент внутри подложки (лента), у подложки и панели `overflow: hidden`, страница под окном не прокручивается, шапка и поле ввода остаются на месте (Playwright).
2. После «Объясни» из теста и после быстрых кнопок в ленте нет строк с `"version"`, `"components"`, `"wires"` и вида `Наставник видит:` (тест с подменой ответа ИИ), контекст уходит в запросе отдельным полем.
3. Ответ с `**жирным**`, списком и блоком кода показан без символов `**`, `#` и обратных кавычек, код в блоке с кнопкой «Копировать» (unit-тест отрисовщика); сохранённая старая история с JSON при загрузке очищается (unit-тест миграции).
**Dependencies:** none
