# ArduHub Video Landing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Выполнять задачи последовательно в текущей ветке, отмечать шаги и записывать результаты в docs/progress.md. Пользователь прямо поручил сначала подготовить внутренний план, затем сразу выполнить редизайн.

**Goal:** Перестроить главную ArduHub по структуре домашней страницы Neuralese из присланной записи: простой первый экран с точечным фоном, большой ролик, три чередующихся видеоблока в ярких рамках, четыре цветные карточки, FAQ и короткий финальный призыв.

**Architecture:** Главная остаётся Next.js Server Component. Новый лендинг использует существующие Header, Footer, Faq и Reveal, отдельный scoped stylesheet и один клиентский VideoFrame для ленивого воспроизведения локальных MP4. Видео записываются из собственного интерфейса в изолированных гостевых браузерных сессиях; запись Neuralese служит только визуальным референсом.

**Tech Stack:** Next.js App Router, React, TypeScript, Tailwind CSS, motion, pnpm, Playwright для записи и проверки, установленный FFmpeg для локального кодирования H.264.

**Spec:** AGENTS.md; текущий запрос пользователя; исходная docs/ArduHub_landing_spec.md в части правдивого текста, адаптивности и доступности. Новое указание пользователя заменяет прежний порядок секций и требование парящих Arduino-компонентов. Cobalt Mono и Inter сохраняются; serif повторно не добавлять.

## Контракты

`VideoFrame({ id, src, poster, label, tone, featured? })`, где tone = 'rainbow' | 'blue' | 'pink' | 'green', id — уникальный string. Видео без аудио, muted, playsInline, loop, preload='none', с фиксированным aspect-ratio 16/10. Элемент video существует в SSR, src присваивается лишь при приближении к viewport; poster и содержательная подпись доступны сразу.

При появлении в viewport и разрешённом движении видео воспроизводится. При уходе за экран, скрытии вкладки или reduced motion оно останавливается. Ошибка autoplay перехватывается; показывается кнопка запуска. Ошибка файла оставляет poster и сообщение о недоступности. Кнопка pause/play доступна с клавиатуры. После ручной паузы автоматическая прокрутка не должна снова включать видео. При reduced motion автоматического воспроизведения нет; ручной запуск разрешён. Никаких циклических setInterval в React.

`DotBackdrop()` рендерит стабильную сетку точек по краям, без случайности во время hydration. Анимируются только opacity/transform; при reduced motion всё статично. Точки не перекрывают клики и не снижают контраст заголовка.

## Review Focus

1. Первый экран и точечный декор читаются на 360 px и при масштабе текста 200%.
2. Ручная пауза не отменяется IntersectionObserver, вкладкой или переключением reduced motion.
3. Без JS видны заголовки, постеры, ссылки и ответы FAQ.
4. При сетевой ошибке вместо пустого чёрного прямоугольника остаётся понятный poster/fallback.
5. Старые якоря меню не ведут в удалённые секции; регистрация и вход продолжают работать.
