# ЧАСТЬ B. Решения для этого файла

## B5. Звуковые эффекты

Звуки синтезируются в браузере (Web Audio API), файлов и лицензий не нужно. Модуль `src/lib/sfx.ts`, вызов `playSfx(id)`.

| id                | Когда                                | Звук                           | Длина  |
| ----------------- | ------------------------------------ | ------------------------------ | ------ |
| `tap`             | нажатие главных кнопок               | мягкий щелчок                  | 40 мс  |
| `part_drop`       | деталь поставлена на полотно         | короткий «тук»                 | 90 мс  |
| `wire_snap`       | провод подключён к пину              | щелчок-защёлка                 | 80 мс  |
| `correct`         | верный ответ теста, верная проверка  | два нарастающих тона           | 300 мс |
| `wrong`           | неверный ответ                       | мягкий низкий двойной «бип»    | 250 мс |
| `check_done`      | отмечена подзадача практики          | приятный колокольчик           | 350 мс |
| `run_start`       | нажато «Запустить»                   | нарастающий «бип»              | 200 мс |
| `hint`            | открыта подсказка                    | тихий звонок                   | 250 мс |
| `spark_gain`      | получены искры или XP                | серия «монет»                  | 400 мс |
| `streak_ignite`   | серия выросла                        | «вжух» и потрескивание         | 700 мс |
| `lesson_complete` | урок пройден                         | фанфара из трёх нот и мерцание | 1,2 с  |
| `level_up`        | новый уровень                        | восходящее арпеджио            | 1 с    |
| `unlock`          | открылся новый урок или уровень      | щелчок замка и мерцание        | 600 мс |
| `purchase`        | покупка                              | хлопок и блеск                 | 600 мс |
| `deny`            | не хватает искр, действие недоступно | короткий низкий тон            | 200 мс |
| `mentor_open`     | открыт чат наставника                | лёгкий «поп»                   | 150 мс |

Правила: звук не играет при загрузке страницы, `AudioContext` запускается при первом нажатии пользователя, один и тот же звук не чаще раза в 80 мс, одновременно не больше 6 звуков, громкость по умолчанию 50%. Выключатель 🔊 и 🔇 в верхней панели кабинета и в профиле, выбор запоминается. Звуки включены по умолчанию.

[ASSUMPTION: звуки включены по умолчанию, потому что ты просил звуковые эффекты. Если нужно наоборот, меняется одно значение по умолчанию]

## Общие правила для всех задач

1. Тексты только из `content/*.ts`, проверяются `pnpm lint:copy` (см. G-2).
2. Размеры шрифтов только по токенам «Типографика v2» (`F-1`), цели нажатия не меньше 44 px.
3. Анимации через `motion.ts` (`transform` и `opacity`), при «уменьшить анимацию» движение заменяется мгновенной сменой состояния.
4. Звуки только через `playSfx(id)` из `sfx.ts`, никаких `new Audio()` в компонентах.
5. Каждая задача заканчивается тестами из её критериев. Задача не считается готовой, пока тесты зелёные.
6. Служебные страницы (`/dev/*`) не попадают в меню и `sitemap.xml`.
