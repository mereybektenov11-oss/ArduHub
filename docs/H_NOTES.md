# H — причины, изменения и проверка

## H-3: причина до правки

В `StatBar` значок, `AnimatedCount` и подпись сейчас являются тремя соседними элементами. Общие правила `.dash-statbar > div` в `dashboard.css` раскладывают их через grid, а правила `.kids-stats` и мобильные переопределения `event-feedback.css` меняют строки/размещение на главной. Поэтому число и подпись не образуют единый вертикальный блок, а геометрия главных счётчиков отличается на узком экране. Для H-3 извлекаю StatBar и добавляю отдельный класс только при `includeLevel` (главная), с локальными правилами, сохраняя безусловную раскладку уроков и прежние размеры/цвета/тексты.

## H-2 — установленная причина до изменений
API уже передаёт context отдельно. В MentorChat строка контекста выводит context.scene.split(';')[0], то есть JSON схемы; ответы отображаются как сырой Markdown. История хранится массивом без очистки. Ограничения высоты modal/log и overflow у notes создают вложенную прокрутку. Исправление затрагивает фактический компонент src/components/cabinet/MentorChat.tsx (необходимое уточнение разрешённой области окна наставника), помощники mentor и стили только наставника. Новые тексты интерфейса не требуются.

## H-4: проверка до правки

До сборки H сняты контрольные изображения неизменённой G-4 сборки (порт 3000) в ignored `reports/h/before`: главная с маской счётчиков, карта, магазин, практика, проекты, урок; дополнительно сохранена разметка шапок. Причина отсутствия защиты области: общего исполняемого ограничения diff относительно G-4 не было. H-4 добавляет проверку объединения committed/working/untracked изменений, с точным перечнем необходимых существующих мест вызова и явными исключениями только для заранее существовавших нетрекнутых `outputs/` и `docs/assets/`.

Изменения H-3: вынес `StatBar` в `src/components/shell/StatBar.tsx`, сохранил экспорт через `RightRail.tsx` для текущих вызовов, добавил только home-scoped правила в `src/styles/h-stats.css` и импортировал её из `StatBar.tsx`. Главные показатели теперь имеют общую строку значка и двухстрочного текста; кольцо уровня совпадает по размеру с 32×32 значками и содержит центрированный номер, подпись центрируется по вертикали рядом. На ширине до 767 px главная раскладывает счётчики в два столбца. Параметр `includeLevel` оставляет счётчики панели урока без нового класса и новых правил.

Проверка: ESLint по `StatBar.tsx`, `RightRail.tsx` и `layout.tsx` прошёл без предупреждений. Общий `tsc --noEmit` пока сообщает об имеющейся несвязанной ошибке `variant` в `src/components/mentor/MentorAssistant.tsx:53`; файл наставника не менялся. Сборку не запускал по указанию оркестратора.

## H-1 — проверенная причина
Общий Modal вызывает showModal(), но CSS .cab-modal не задаёт центрирование и margin:auto; сброс Tailwind убирает браузерные отступы dialog. Заголовок находится в общей строке с кнопкой закрытия и выравнивается влево. Гипотеза о transform как основной причине для native top-layer dialog не подтверждена. NameDialog отдельно повторяет этот способ показа; стикер, сундук и уведомления используют независимые fixed-позиции. Решение: общий портал в body с явным центрированием, очередью и сохранением native dialog для фокуса/Esc; отдельно неблокирующие уведомления. Логику наград и содержимое не менять.

H-3 integration adjustment: following coordination with the parent task, the scoped stylesheet is imported directly by `StatBar.tsx`; `src/app/app/layout.tsx` has no H-3 change.
H-3 geometry clarification: `.kids-level-ring` now uses 32×32 px to match the existing 32×32 px stat icons; the number remains centered inside the ring and its label is vertically centered beside it.

H-2: контекст схемы больше не попадает в видимую строку; история мигрирует в {version:2,messages} с удалением context/system и JSON. Ответы рендерятся безопасными React-элементами (без HTML); существующая кнопка копирования сохранена. Лента — единственная вертикальная прокрутка; быстрые действия горизонтальны. Новые строки UI не добавлены. Проверка: 4 unit-теста h-mentor, целевой ESLint — успешно. Сборка и проверка viewport выполняются родительским агентом последовательно с H-1.

H-2 integration review: сохранена исходная очистка HTML/лимит 500 символов у запроса API; удаление служебных данных применяется только к отображению и сохранённой истории. Очистка HTML не затрагивает fenced C++: #include <Arduino.h> и сравнения < / > сохраняются, добавлен регрессионный тест. Теперь 5 unit-тестов h-mentor и целевой ESLint проходят.

H-3 visual QA adjustment: restored the prior 64 px stat-item footprint while keeping each icon and its copy vertically centered, so following home content does not shift.

## Итог реализации H-1—H-3

Общие окна перенесены в портал непосредственного уровня `body`, с явным центрированием и очередью. Native dialog сохраняет фокус и обработку Esc; подложка блокирует прокрутку страницы. Неблокирующие уведомления центрированы отдельно, а их время показа начинается после выхода из очереди. Стикер отмечается увиденным при фактическом открытии окна. Масштаб чтения наследуется порталом из настроек кабинета. Жёлтая заливка заголовка без выделения текста не воспроизвелась.

В чате удалён вывод JSON схемы; контекст по-прежнему передаётся API отдельно. Старая история мигрирует в версию 2, служебные фрагменты скрываются, разрешённое форматирование отображается безопасными React-элементами. В окне прокручивается только лента; проверено положение поля ввода при уменьшении visualViewport до 320 px, имитирующем экранную клавиатуру. Копирование C++ сохраняет `#include <Arduino.h>` и знаки сравнения.

Главные счётчики собраны в выровненные группы. Сохранена их прежняя внешняя высота 64 px, чтобы не сдвигать остальную главную; панель урока использует прежнюю разметку. Новый `div` для текста сохраняет прежний цвет чисел, не наследуя оформление декоративного значка.

## Поддержка существующих браузерных проверок

Полный прогон выявил старые сценарии до G1—G3: без обязательного ника, с неподтверждёнными завершёнными уроками, с прежними подписями кнопок и отдельной страницей наставника. Такие фикстуры и селекторы приведены к действующему интерфейсу. Сохраняются проверки точной стоимости, отсутствия повторной награды, ввода/вывода схемы, сохранения и импорта проектов, доступности и клавиатуры. Декоративный SVG-текст `aria-hidden` исключён только из аудита размера читаемого текста. После действий, порождающих уведомления, тесты закрывают реальные окна, не начисляя наград тестовым обходом. Для ленивой палитры прокручивается сам визуальный элемент компонента.

Эти изменения не возвращают старый интерфейс и не меняют продуктовую логику. Рабочая база и публичный сайт не изменялись. Компилятор для браузерных проверок использует существующий доверенный локальный шлюз Arduino CLI на loopback; это не изолированная публичная среда.

## Уточнения после полного прогона

Расширенная проверка сундука выявила оставшийся `translateX(-50%)` прежнего уведомления `+N`: внутри центрированной сетки он повторно сдвигал элемент. Это смещение снято только для уведомления в новом портале. Для возврата фокуса закрытие dialog выполняется до удаления DOM; если обновление прогресса пересоздало исходную кнопку, находится её актуальная замена по стабильному id, `data-tour` или доступному названию.

Старый мобильный тест палитры перечислял категории раньше загрузки редактора, получая пустой список. Теперь сначала ожидаются все 51 кнопка, категории открываются по стабильным позициям и проверяется загрузка каждого видимого компонента. Аудит контраста ответа в тесте урока ожидает завершения анимации появления, сохраняя проверку axe без исключения правила контраста. Тест геометрии карты использует фактический `.island-map-stage`.
