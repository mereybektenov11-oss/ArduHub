# Исправления редактора и подключение аккаунтов — 17.10.2026

Обновление: локальная компиляция изменённого кода теперь подключена и проверена; добавлена очистка всех проводов. Текущее состояние — [clear-wires-and-run.md](clear-wires-and-run.md). Указанное ниже ограничение Docker относится к исходной проверке.

## Что изменено

- Запуск доступен из вкладки «Тесты» и шага «Код». Он отправляет текущий код в `/api/compile` и исполняет полученный HEX в AVR Worker. Проверка поведения выполняется по трассе симуляции; неверная схема не получает награду.
- Переход между шагами больше не пересоздаёт весь Workspace. Сохраняются история отмены и результаты тестов. Начальная вкладка меняется при переходе к коду.
- Провода располагаются над корпусами, пины — над проводами. Это исправляет перехват нажатий корпусом Arduino. Выбор провода даёт кнопку «Удалить провод» возле масштаба. Работают Delete, отмена, повтор и сохранение схемы.
- Убраны всплывающие подписи деталей и native-title пинов. Захват для перемещения занимает корпус детали; доступные названия сохранены через aria-label.
- Левая панель задания объединена в одну поверхность с разделителями. Добавлены внутренние интервалы, отдельная группа кнопок и отступы ожидаемого результата. Использованы существующие карточки и токены ArduHub.
- Ошибки регистрации и отправки письма больше не маскируются сообщением об успешной отправке.

## Supabase

С согласия пользователя создан отдельный проект **ArduHub**, `wjdxephhhedxertzgjnu`, `eu-central-1`, в выбранной им организации. Создание оценено Supabase в $0/месяц. LingoFormKZ и TremoFIX не менялись. Публичный URL и publishable key находятся только в локальном окружении; service-role ключ не требуется.

Применены обе миграции. История облачной базы согласована с версиями локальных файлов: `20261015190609` и `20261017131620`. На всех девяти публичных таблицах включён RLS, магазин содержит 10 записей. Проверка security advisor не вернула предупреждений уровня WARN/ERROR; INFO об отсутствии политик для waitlist_signups ожидаем: публичный доступ к списку заявок закрыт.

Site URL: `http://127.0.0.1:3000`. Разрешены точные callback URL регистрации и сброса пароля для 127.0.0.1:3000, localhost:3000 и тестового 127.0.0.1:3100. По отдельному явному согласию пользователя отключено подтверждение почты для прототипа. Встроенный SMTP Supabase допускает письма только участникам организации; собственный SMTP пока не настроен, восстановление пароля письмом не считается проверенным.

Реальные запросы signup → создание профиля → signOut → signIn успешны. Анонимное чтение профилей закрыто. Начальные балансы тестового аккаунта: 0 искр и 50 токенов. Браузерная проверка перенесла гостевой прогресс в облако и прочитала его во втором браузере; выход также проверен. Выделенный QA-аккаунт не является данными ученика; его доступ хранится в игнорируемом `.env.e2e.local`, значения в отчёты не записываются.

Повторная проверка API: `node --env-file=.env.local scripts/check-supabase-auth.mjs`. Скрипт создаёт новый выделенный QA-аккаунт. Браузерная проверка: `node --env-file=.env.local --env-file=.env.e2e.local node_modules/@playwright/test/cli.js test tests/e2e/dashboard-auth-live.spec.ts`.

## Проверка и ограничения

Пройдены сборка, линтер, TypeScript, lint:type, проверка форматирования и отсутствия серверных ключей в клиенте. Пройдены 20 целевых модульных тестов и 16 разных браузерных сценариев: реальная AVR-симуляция из «Тестов», первый урок, проекты, монитор порта, удаление проводов, отмена, Delete, отсутствие всплывающих подписей, перемещение за корпус, адаптивность, вращение/масштаб, Servo, реальный облачный вход и честное отображение ошибок почтового сервиса. 8 основных сценариев повторены на окончательной сборке; 2 сценария ошибок почты также проверены на ней.

Материалы: `reports/usability/supabase-auth.json`, `reports/usability/supabase-auth-settings.png`, `reports/usability/guide-mobile.png`, `tests/e2e/lesson-usability.spec.ts`.

Сервис Docker-компиляции произвольных скетчей по-прежнему не запущен. Проверенные учебные скетчи используют настоящие предварительно скомпилированные прошивки; изменение произвольного исходника требует запуска изолированного сервиса из `compiler-service/README.md`. Внешней публикации Vercel нет.
