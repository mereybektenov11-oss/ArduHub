# Шрифты

Официальные файлы из Google Fonts, загружены 15 октября 2026 года:

- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope
- Inter: https://github.com/google/fonts/tree/main/ofl/inter

Содержат кириллицу. Используются через `next/font/local` с `display: swap`. Лицензии OFL сохранены рядом. Удалённый загрузчик `next/font/google` в этом окружении падал на обработке адреса файла шрифта; локальные официальные файлы сохраняют выбранные гарнитуры и убирают сетевую зависимость сборки.

Для выдачи браузеру подготовлены WOFF2: Inter с весами 400–700 и оптическим размером 14, Manrope 700–800. Сохранены базовая латиница, русская кириллица, доступные в исходнике казахские буквы, пунктуация и тенге. Inter содержит весь казахский алфавит; в оригинальном Manrope отсутствуют ӘҒҚҢҰ и их строчные варианты. Перед добавлением казахских заголовков нужно выбрать гарнитуру с полным набором. Все русские буквы проверены в обоих итоговых файлах. Использованы fontTools subset/varLib.instancer и Brotli. Размеры: Inter 30 416 байт, Manrope 20 872 байт. Оригинальные TTF остаются источником для расширения набора символов.
