# Шрифты

Официальные файлы из Google Fonts, загружены 15 октября 2026 года:

- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope
- Inter: https://github.com/google/fonts/tree/main/ofl/inter

Содержат кириллицу. Используются через `next/font/local` с `display: swap`. Лицензии OFL сохранены рядом. Удалённый загрузчик `next/font/google` в этом окружении падал на обработке адреса файла шрифта; локальные официальные файлы сохраняют выбранные гарнитуры и убирают сетевую зависимость сборки.

Для выдачи браузеру подготовлены WOFF2: Inter с весами 400–700 и оптическим размером 14, Manrope 700–800. Сохранены базовая латиница, русская кириллица, доступные в исходнике казахские буквы, пунктуация и тенге. Inter содержит весь казахский алфавит; в оригинальном Manrope отсутствуют ӘҒҚҢҰ и их строчные варианты. Перед добавлением казахских заголовков нужно выбрать гарнитуру с полным набором. Все русские буквы проверены в обоих итоговых файлах. Использованы fontTools subset/varLib.instancer и Brotli. Размеры: Inter 30 416 байт, Manrope 20 872 байт. Оригинальные TTF остаются источником для расширения набора символов.

08.11.2026: VT323 Regular загружен из https://github.com/google/fonts/tree/main/ofl/vt323 для фонового кода на главной. Оригинальный TTF, WOFF2 без урезания набора символов и лицензия VT323-OFL.txt сохранены рядом. Кириллица в оригинальном VT323 отсутствует, для неё используется Inter.

08.11.2026: по уточнению пользователя кириллица фоновых компонентов использует пиксельный Tiny5 вместо Inter. Официальный источник: https://github.com/google/fonts/tree/main/ofl/tiny5. Сохранены TTF, WOFF2 и Tiny5-OFL.txt. Проверено наличие всех 66 русских букв. VT323 остаётся первым шрифтом для латиницы.

08.11.2026: пользователь выбрал Monocraft для названий компонентов вместо Tiny5. Локальные Monocraft-Regular.ttf/woff2 взяты из официального релиза v4.2.1: https://github.com/IdreesInc/Monocraft/releases/tag/v4.2.1; лицензия Monocraft-LICENSE.txt сохранена рядом. Проверены все 66 русских букв. Названия на латинице также используют Monocraft; код остаётся VT323.

08.11.2026: по прямому запросу пользователя hero использует Spectral Medium 500, слово «Заработает?» — настоящий Spectral Medium Italic 500. Источник https://github.com/google/fonts/tree/main/ofl/spectral, TTF/WOFF2 и Spectral-OFL.txt сохранены локально; кириллица заголовка проверена.
